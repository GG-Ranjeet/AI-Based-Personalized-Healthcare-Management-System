# AI-Based Personalized Healthcare Management System

This is a template for a MERN (MongoDB, Express, React, Node.js) stack project to get started quickly.

## How to get install and get started with the project

### Step 1: clone the project

Open the terminal and paste the following command with preferred directory name.

`git clone https://github.com/GG-Ranjeet/potential-dollop.git <directory_name>`

### Step 2: Install the Dependencies

Use command `npm install:all` to install all the modules required for both client and server

### Step 3: Set up Environment variable

create a file called `.env` in both client folder and server folder and copy and paste the content from `.env.exanple` file into this.

### Step 4: Run the development server

Run the server with command `npm run dev` this start both client and server.

## Available Scripts

In the project directory, you can run the following commands using npm:

### `npm run install:all`
Installs dependencies for the root directory, the client, and the server simultaneously. Run this first when setting up the project.

### `npm run dev`
Concurrently runs both the client and the server in development mode.

### `npm run client`
Runs only the client application.

### `npm run server`
Runs only the server application.

### `npm run build`
Builds the client application for production.

## Project Structure
- `/client` - React frontend
